# task1: Сегментация деталей трубопроводной арматуры по данным LiDAR

## Что делает проект
Семантическая сегментация облаков точек промышленной арматуры (корпус, фланцы, болты, гайки и т.д.).  
Входные данные – ASCII `.ply` файлы (координаты xyz + метка класса).  
Модель относит каждую точку облака к одному из классов деталей.

## Используемые модели
- **PointNet** – базовая архитектура для неупорядоченных облаков точек.
- **PointNet++** – иерархическая модель с захватом локальной геометрии.
- **DGCNN** – динамические графовые свёртки (EdgeConv).

## Запуск
1. Поместить `.ply` файлы в папку `dataset/`.
2. Установить зависимости:
   ```bash
   pip install torch tqdm numpy scikit-learn matplotlib seaborn
   ```

- Графики обучения (*_curves.png)

- Матрицы ошибок (*_confusion.png)

- Вывод метрик в ipynb файле 

# task2:  Адаптивная реконструкция поверхностей по облакам точек ТЛО

Проект предназначен для автоматической реконструкции трёхмерных поверхностей (mesh) из сегментированных облаков точек в формате PLY.  
Входные данные — PLY-файлы с координатами `x,y,z` и целочисленной меткой сегмента `scalar_Label`.  
Для каждого сегмента вычисляются геометрические признаки, определяется тип (`plane`, `tube`, `sphere`, `complex`) и применяется подходящий алгоритм построения сетки.  
Результат — объединённая треугольная сетка и файл с метриками качества (RMSE для каждого сегмента).

## Основные возможности

- Загрузка PLY с полями `x,y,z,scalar_Label`
- Фильтрация шумов (статистический outlier removal) и нормализация облака
- Извлечение сегментов по уникальным меткам
- Вычисление признаков: линейность, planarность, сферичность, плотность, нормальная согласованность, связность
- Классификация сегмента и выбор метода реконструкции:
  - **plane** → alpha‑shape
  - **tube** → ball‑pivoting
  - **sphere** → Poisson surface reconstruction
  - **complex** → Poisson (более глубокая)
- Оценка качества по RMSE между исходными точками и реконструированной поверхностью
- Сохранение итоговой mesh в формате PLY
- Визуализация сравнения исходного облака и полученной сетки

## Зависимости

- `numpy`
- `open3d`
- `scipy`
- `scikit-learn`
- `networkx`
- `plyfile`
- `pillow` (опционально, для сохранения изображений)

Установка всех зависимостей:
```bash
pip install numpy open3d scipy scikit-learn networkx plyfile pillow
```

# task3: Геометрический анализ сегментов облака точек

## Назначение
Данный модуль выполняет детальный геометрический анализ сегментов 3D-облака точек. Результаты анализа используются для классификации сегментов и выбора оптимального метода реконструкции поверхности.

## Этапы анализа

### Плотность точек
- Вычисление среднего расстояния между соседними точками
- Оценка равномерности распределения
- Выявление областей разреженности/сгущения  
- **Результат**: числовая оценка + качественная интерпретация (низкая/средняя/высокая плотность)

### Форма распределения
- Оценка вытянутости и доминирующего направления
- Определение изотропности/анизотропии

### Структура поверхности
- Оценка кривизны
- Выявление гладких и резких изменений

### Согласованность нормалей
- Вычисление нормалей для всех точек
- Оценка степени согласованности направлений

### Топологическая связность
- Определение связности сегмента, разрывов, изолированных частей
- Анализ количества соседей, отверстий и пропусков
